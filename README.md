# 사진 보관함

휴대폰과 PC의 사진·동영상을 **갤러리 앱처럼** 모아 보고, **백업 파일(ZIP)로 내보내고 복원**하는 웹 앱입니다.
설치 파일 없이 브라우저에서 바로 열 수 있고, 홈 화면에 추가하면 일반 앱처럼 전체 화면으로 쓸 수 있습니다(PWA).

## 주요 기능

**갤러리**
- 촬영 날짜(EXIF)별로 묶어 보여주는 사진 그리드 — 오늘 / 어제 / 날짜별
- 보기 크기 3단계(작게 · 보통 · 크게), 동영상 길이 표시, 즐겨찾기 하트 표시
- 전체 화면 뷰어: 좌우로 밀어 넘기기, 두 손가락 확대, 두 번 탭 확대, 아래로 밀어 닫기, 동영상 재생, 상세 정보
- 길게 눌러 여러 장 선택(PC는 마우스를 올리면 나오는 체크 버튼, Shift·Ctrl 클릭) → 공유 · 즐겨찾기 · 앨범 추가 · 저장 · 삭제

**보정 탭 (하단 메뉴)**
- **자동 보정**: 사진을 분석해서 밝기·대비·하이라이트·그림자·화이트밸런스·색감을 알맞게 맞춤. 강도(자연스럽게·보통·강하게) 선택
- **보정 추천**: 보관함을 분석해 어두운 사진, 너무 밝은 사진, 뿌연 사진, 색이 치우친 사진을 찾아 줌 → 보정 전/후를 나란히 보고 한꺼번에 보정
- 사진을 골라 한꺼번에 자동 보정(원본 보관하고 바꾸기 / 사본으로 저장), 직접 세부 보정, 보정한 사진 모아 보기

**사진 편집 (GPU 보정 엔진)**
- 슬라이더를 움직이는 즉시 결과를 보여주는 WebGL2 엔진. 저장은 원본 해상도(최대 1,600만 화소)로 처리
- **보정** 탭: 자동 보정(노출·대비·하이라이트·그림자·흰색/검정·화이트밸런스·생동감 자동 계산), 강도, 장면별 보정(자동·인물·풍경·음식·야경·HDR·문서). 계산된 값은 ‘조정’ 탭 슬라이더에 그대로 나타나서 하나씩 다듬을 수 있음
- **조정** 탭
  - 빛: 노출(EV), 대비, 하이라이트, 그림자, 흰색 계열, 검정 계열, 밝기 — 하이라이트·그림자는 주변 밝기를 보고 부분별로 조절(경계를 지켜 후광이 생기지 않음)
  - 색상: 색온도, 색조, 생동감, 채도
  - 효과: 명료도, 텍스처, 안개 제거, 비네팅, 그레인, 페이드
  - 디테일: 선명하게, 노이즈 감소(밝기 노이즈 + 색 노이즈)
  - 톤 커브(RGB·R·G·B, 점을 끌어서 편집), 색상별 조정(8색 색조·채도·밝기), 컬러 그레이딩(그림자·중간 톤·하이라이트 색, 균형)
  - 슬라이더 이름을 두 번 누르면 초기화, 바뀐 묶음은 점으로 표시, 히스토그램 표시
- **인물** 탭 (뷰티): 얼굴을 찾아(여러 명 가능) 부위별로 자연스럽게 다듬음. 사진은 기기 안에서만 처리
  - 자동 뷰티: 티 나지 않는 정도로 피부·얼굴형·눈·입을 한 번에
  - 피부: 피부 보정(얼굴 피부만, 결은 살림), 화사하게, 다크서클 완화, 볼 혈색, 잡티 제거 브러시
  - 얼굴형: 얼굴 갸름하게(V라인), 턱 길이
  - 눈·코·입: 눈 크게, 눈 또렷하게, 코 슬림, 입술 혈색, 치아 미백
  - 얼굴을 찾지 못한 사진은 피부 보정만 적용
  - 모든 항목은 최대로 올려도 실제 사람처럼 보이는 범위까지만 바뀜 (예: 얼굴 갸름하게 최대 한쪽 3.5%, 턱 길이 ±2.5%, 눈 최대 약 9%)
  - 피부 보정은 주파수 분리 방식: 얼룩·잡티만 고르게 하고 모공·피부결은 원본 해상도 그대로 남겨 확대해도 뭉개지지 않음
  - **보정 지우개**: 문지른 곳만 얼굴형·피부·입술 등 인물 보정과 성형·부분 보정이 빠지고 원래대로 (되살리기도 가능, 밝기·색감·필터는 유지)
- **성형** 탭 (손으로 직접 모양 다듬기): 밀기(턱선·볼·허리·팔 라인), 크게(누르고 있으면 점점 커짐), 작게, 되돌리기 브러시. 브러시 크기·세기 조절, 두 손가락으로 확대해서 섬세하게
- **부분** 탭 (칠해서 보정하는 브러시): 밝게, 어둡게, 매끄럽게, 선명하게, 미백, 채도 높게/낮게, 따뜻하게, 차갑게, 지우개. 여러 번 문지르면 더 강해지고, ‘칠한 곳 보기’로 칠한 영역을 확인
- 저장은 원본 해상도·고화질(JPEG 품질 95)로 하고, 미리보기와 저장 결과가 같습니다
- 성형·부분 보정·잡티 제거는 모두 획 단위로 되돌리기/다시 실행이 되고, 원본 해상도로 저장
- **자르기** 탭: 비율 자르기, 회전·반전, 기울기 보정, 세로·가로 원근 보정
- **필터** 16종: 맑음, 따뜻함, 시원함, 필름, 인물 필름, 초록 필름, 시네마, 빈티지, 파스텔, 카페, 음식, 야경, 흑백, 느와르, 세피아 (커브·컬러 그레이딩·그레인 조합, 강도 조절)
- **그리기**: 펜, 형광펜, 모자이크(얼굴·번호판·개인정보 가리기)
- 두 손가락·마우스 휠로 확대해서 디테일 확인, 실행 취소/다시 실행, 누르고 있으면 원본과 비교
- **저장**(편집 전 원본을 보관해서 언제든 ‘원본으로 되돌리기’) 또는 **사본으로 저장**
- WebGL2를 쓸 수 없는 오래된 기기에서는 기본 보정만 적용

**찾기 · 보기**
- 검색: 날짜(‘2025년 10월’), 앨범 이름, 파일 이름, 동영상·즐겨찾기·편집·스크린샷, 올해·작년
- 추억: 사진 탭 위에 ‘N년 전 오늘’ 카드
- 슬라이드쇼, 오른쪽 손잡이로 월 단위 빠른 스크롤
- 두 손가락으로 벌리고 오므려 사진 크기 조절(PC는 Ctrl + 마우스 휠)
- 사진 정보: 카메라·렌즈, 조리개·셔터·ISO·초점거리, 촬영 위치(지도 링크)
- 촬영 날짜·시간 변경, 앨범 표지 지정

**정리 · 도구**
- 정리 도우미: 비슷한 사진(연속 촬영) 묶음에서 가장 선명한 사진만 남기기, 흐릿한 사진, 스크린샷, 큰 동영상
- 숨긴 항목: 사진 탭·검색·추억에서 숨기기. 앱 잠금을 켜면 열 때마다 PIN 확인
- 콜라주 만들기(2~9장, 배치·비율·간격·모서리·배경색), 동영상의 지금 장면을 사진으로 캡처
- 길게 누른 뒤 끌어서 여러 장 선택, ‘작게’ 보기에서는 월 단위로 묶어 보기
- 앨범 만들기 · 이름 바꾸기 · 삭제, 보관함에서 골라 넣기
- 즐겨찾기 · 동영상 모아보기
- 휴지통: 삭제한 항목을 30일 동안 보관 후 자동 삭제, 복원 가능

**백업**
- 사진·동영상 여러 장 한 번에 추가, PC에서는 폴더 통째로 추가와 끌어다 놓기 지원
- 같은 사진은 파일 이름이 달라도 내용으로 알아보고 자동으로 건너뜀(중복 방지)
- 안드로이드: 앱을 홈 화면에 설치하면 갤러리 앱에서 **공유 → 사진 보관함**으로 바로 보관
- **백업 파일 내보내기**: 전체 또는 아직 내보내지 않은 새 항목만 ZIP으로 저장(1GB 단위로 나눔)
- **백업 파일에서 복원**: 다른 기기·브라우저에서 ZIP을 고르면 사진, 촬영 날짜, 앨범, 즐겨찾기까지 그대로 복원
- 저장공간 사용량 표시, 브라우저가 사진을 지우지 않도록 하는 ‘저장공간 보호’ 요청
- 인터넷이 끊겨도 동작(오프라인 지원)

**설정**
- 테마: 시스템 설정 따르기 / 밝게 / 어둡게
- 앱 잠금: PIN 4자리, 자동 잠금 시간(바로·1분·5분). 화면 잠금이며 파일 자체를 암호화하지는 않습니다.
  PIN을 잊으면 모든 데이터를 지우고 초기화해야 하니 백업 파일을 꼭 만들어 두세요.
- 공유할 때 위치(GPS) 정보 빼기 (기본 켜짐)
- 저장공간 현황, 모든 데이터 삭제

## 사진은 어디에 저장되나요?

사진 원본은 **이 기기의 브라우저 안(IndexedDB)** 에만 저장되며 외부 서버로 전송되지 않습니다.
따라서 휴대폰 분실·초기화·브라우저 데이터 삭제에 대비하려면 **백업 탭 → 백업 파일 내보내기**로 만든 ZIP 파일을
PC, 외장 드라이브, 구글 드라이브 같은 클라우드에 따로 보관해 주세요. 새 기기에서는 **백업 파일에서 복원**으로 되살릴 수 있습니다.

> iPhone(Safari)은 홈 화면에 추가하지 않은 사이트의 저장 데이터를 오래 사용하지 않으면 지울 수 있습니다. iPhone에서는 꼭 **공유 → 홈 화면에 추가** 후 사용하세요.

## 실행하기

빌드 과정이 없는 정적 웹 앱입니다. 서비스 워커와 보안 기능 때문에 `file://`로 직접 열지 말고 웹 서버로 열어야 합니다.

**내 컴퓨터에서 확인**
```bash
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

**GitHub Pages로 배포 (휴대폰에서 쓰기)**
1. 이 코드를 `main` 브랜치에 올립니다.
2. 저장소 **Settings → Pages** 에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 저장합니다.
3. 잠시 후 `https://<사용자이름>.github.io/<저장소이름>/` 주소로 접속합니다.
4. 휴대폰에서 그 주소를 열고 **홈 화면에 추가(앱 설치)** 하면 앱처럼 사용할 수 있습니다.

```
icons/                앱 아이콘

```

## 알아두면 좋은 점

- HEIC 등 브라우저가 열지 못하는 형식도 원본은 그대로 보관되고 백업에도 들어갑니다(썸네일만 아이콘으로 표시). 이런 사진은 편집할 수 없습니다.
- 편집해서 저장한 사진은 백업 파일에 편집본이 들어갑니다. 아주 큰 사진(1,600만 화소 초과)은 저장할 때 브라우저 한계에 맞게 조금 줄어듭니다.
- 인물 탭을 처음 열 때 얼굴 인식 엔진(약 20MB)을 한 번 내려받습니다. 사진은 서버로 보내지 않고 기기 안에서만 분석합니다.
- 4GB가 넘는 동영상 한 개는 ZIP에 넣을 수 없어 뷰어의 다운로드 버튼으로 따로 저장해야 합니다.
- 보관할 수 있는 총 용량은 브라우저가 정하며, 백업 탭에서 현재 사용량과 최대 용량을 확인할 수 있습니다.
