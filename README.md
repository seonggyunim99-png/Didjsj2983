# 사진 보관함

휴대폰과 PC의 사진·동영상을 **갤러리 앱처럼** 모아 보고, **백업 파일(ZIP)로 내보내고 복원**하는 웹 앱입니다.
설치 파일 없이 브라우저에서 바로 열 수 있고, 홈 화면에 추가하면 일반 앱처럼 전체 화면으로 쓸 수 있습니다(PWA).

## 주요 기능

**갤러리**
- 촬영 날짜(EXIF)별로 묶어 보여주는 사진 그리드 — 오늘 / 어제 / 날짜별
- 보기 크기 3단계(작게 · 보통 · 크게), 동영상 길이 표시, 즐겨찾기 하트 표시
- 전체 화면 뷰어: 좌우로 밀어 넘기기, 두 손가락 확대, 두 번 탭 확대, 아래로 밀어 닫기, 동영상 재생, 상세 정보
- 길게 눌러 여러 장 선택(PC는 마우스를 올리면 나오는 체크 버튼, Shift·Ctrl 클릭) → 공유 · 즐겨찾기 · 앨범 추가 · 저장 · 삭제

**정리**
- 앨범 만들기 · 이름 바꾸기 · 삭제, 보관함에서 골라 넣기
- 즐겨찾기 · 동영상 모아보기
- 휴지통: 삭제한 항목을 30일 동안 보관 후 자동 삭제, 복원 가능

**백업**
- 사진·동영상 여러 장 한 번에 추가, PC에서는 폴더 통째로 추가와 끌어다 놓기 지원
- 같은 사진은 파일 이름이 달라도 내용으로 알아보고 자동으로 건너뜀(중복 방지)
- 안드로이드: 앱을 홈 화면에 설치하면 갤러리 앱에서 **공유 → 사진 보관함**으로 바로 보관
- **백업 파일 내보내기**: 전체 또는 아직 내보내지 않은 새 항목만 ZIP으로 저장(1GB 단위로 나눔)
- **백업 파일에서 복원**: 다른 기기·브라우저에서 ZIP을 고르면 사진, 촬영 날짜, 앨범, 즐겨찾기까지 그대로 복원
- 저장공간 사용량 표시, 브라우저가 사진을 지우지 않도록 하는 ‘저장공간 보호’ 요청
- 인터넷이 끊겨도 동작(오프라인 지원), 라이트·다크 모드 자동 전환

## 사진은 어디에 저장되나요?

사진 원본은 **이 기기의 브라우저 안(IndexedDB)** 에만 저장되며 외부 서버로 전송되지 않습니다.
따라서 휴대폰 분실·초기화·브라우저 데이터 삭제에 대비하려면 **백업 탭 → 백업 파일 내보내기**로 만든 ZIP 파일을
PC, 외장 드라이브, 구글 드라이브 같은 클라우드에 따로 보관해 주세요. 새 기기에서는 **백업 파일에서 복원**으로 되살릴 수 있습니다.

> iPhone(Safari)은 홈 화면에 추가하지 않은 사이트의 저장 데이터를 오래 사용하지 않으면 지울 수 있습니다. iPhone에서는 꼭 **공유 → 홈 화면에 추가** 후 사용하세요.

## 실행하기

빌드 과정이 없는 정적 웹 앱입니다. 서비스 워커와 보안 기능 때문에 `file://`로 직접 열지 말고 웹 서버로 열어야 합니다.

**내 컴퓨터에서 확인**
```bash
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

**GitHub Pages로 배포 (휴대폰에서 쓰기)**
1. 이 코드를 `main` 브랜치에 올립니다.
2. 저장소 **Settings → Pages** 에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 저장합니다.
3. 잠시 후 `https://<사용자이름>.github.io/<저장소이름>/` 주소로 접속합니다.
4. 휴대폰에서 그 주소를 열고 **홈 화면에 추가(앱 설치)** 하면 앱처럼 사용할 수 있습니다.

## 파일 구성

```
index.html            화면 뼈대
manifest.webmanifest  앱 설치 정보 (이름, 아이콘, 공유 받기 설정)
sw.js                 서비스 워커 (오프라인 실행, 갤러리에서 공유 받기)
css/style.css         디자인 (모바일 · PC · 다크 모드)
js/app.js             화면 구성과 사용자 동작
js/library.js         보관함 동작 (가져오기, 앨범, 휴지통, 백업 내보내기/복원)
js/viewer.js          전체 화면 뷰어 (스와이프, 확대)
js/media.js           파일 형식 판별, 중복 확인, 촬영 날짜 읽기, 썸네일
js/zip.js             ZIP 만들기 / 읽기 (외부 라이브러리 없음)
js/db.js              IndexedDB 저장소
js/ui.js              아이콘, 대화상자, 알림, 진행 표시
icons/                앱 아이콘
```

## 알아두면 좋은 점

- HEIC 등 브라우저가 열지 못하는 형식도 원본은 그대로 보관되고 백업에도 들어갑니다(썸네일만 아이콘으로 표시).
- 4GB가 넘는 동영상 한 개는 ZIP에 넣을 수 없어 뷰어의 다운로드 버튼으로 따로 저장해야 합니다.
- 보관할 수 있는 총 용량은 브라우저가 정하며, 백업 탭에서 현재 사용량과 최대 용량을 확인할 수 있습니다.
